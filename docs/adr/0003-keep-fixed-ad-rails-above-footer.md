# ADR 0003: 固定広告レールを初期表示からフッター高ぶん上へ置く

## Status

Accepted

## Context

PC記事ページの左右広告レールは、本文の左右ガターへ`position: fixed`で配置している。
通常の閲覧中は安定した位置を保てる一方、`bottom: 1.25rem`では広告が低すぎ、
ページ末尾でフッターと重なっていた。求める位置は、ページ末尾だけ動かすのではなく、
初期表示から広告をフッター1個分だけ上へ固定した位置である。

レールを本文レイアウトへ組み込むと、本文幅、左右対称のガター配置、スクロール中の固定表示を
同時に変更してしまう。今回必要なのは、既存配置を保ったままフッターとの境界だけを直すことである。

## Decision

- レールの`position: fixed`、左右ガター中央、1100px以上という既存契約は維持する。
- 通常の下余白`--rail-bottom: 1.25rem`に、常時`--rail-footer-offset`を加える。
- `--rail-footer-offset`は初回描画用に`6.875rem`を持ち、DOM構築後に実際のフッター高へ補正する。
- スクロール位置によって値を変えない。フッターの折り返しで高さが変わり得るresize時だけ、`requestAnimationFrame`で再計測する。
- 左右レールへ同じ値を適用する。

## Consequences

- 記事本文の途中を含め、最初から最後まで左右レールはフッター1個分だけ高い同じ位置に表示される。
- ページ末尾でも位置は変化せず、フッター上端との間に通常の下余白が残る。
- 配信元、広告HTML、本文カラム、Caddyやnginxの配信構成は変わらない。
- rollbackは`--rail-footer-offset`とフッター高の計測を撤去し、`bottom: var(--rail-bottom)`へ戻す。
