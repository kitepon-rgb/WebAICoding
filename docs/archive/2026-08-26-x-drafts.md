## 4. LiveTR-models

```
LiveTRが最初の起動で取りに行くモデルの置き場を公開した。LiveTR-modelsだ。📦

LiveTRは、海外の動画を止めずに、日本語の透過字幕と読み上げで追うWindows用の道具だ。声紋を識別して、話者ごとに声色を変えて読む。

アプリ本体のソースはここに入っていない。モデルの配布だけを分けて置いてある。🔍
```
